# Odoo 18.0 Migration Modules

This directory will contain Odoo 18.0 modules upgraded from the 16.0 versions.
Modules will be migrated one by one for safer testing and validation.

## Migration Strategy
1. Copy individual module from ../user/ 
2. Upgrade module to Odoo 18.0 compatibility
3. Test the module in isolation
4. Commit the working module
5. Proceed to next module
